# Embedded locus viewer v0.7 — development preview

This feature is under validation. GEL screens candidate associations; an arc does not establish causality. It does not alter the v0.6.1 scientific algorithms or persisted rows.

## Renderer choice

The preview uses an independently written SVG renderer and the existing MIT-compatible `@gmod/bbi` local BigWig reader. It introduces no GeRAFE source or dependency. GeRAFE's architecture was reviewed: its separate browser/track models, linked scales, local data and canvas rendering are useful design references, but its restricted evaluation license prohibits copying its code into GEL without an explicit licensing decision. SVG is convenient for a bounded locus but needs performance validation for dense tracks.

igv.js is an independently licensed browser viewer with BigWig and interaction support; its reference and default-genome loading need explicit control to avoid unexpected external requests. A standalone igv.js 3.8.10 prototype successfully opened a local synthetic FASTA/index and four local synthetic BigWigs in Chromium; its signal shapes visually agreed with the GEL view, and only the local test page and script were requested. Arc-color, relinking, and production integration have not been tested. JBrowse 2 offers a more complete browser and local data support, with a larger integration surface; it was not tested. Plotgardener is an R-based figure-composition package, not this interactive viewer. These alternatives have not been compared in equivalent working tests, so the renderer choice is provisional.

## Use and limitations

Open a persisted run in Workspace, then select a candidate's gene or enhancer. The viewer queries the existing IndexedDB store in a worker for that gene, contrast and evidence layer; it never loads the full result set. It displays up to the first 100 candidates and explicitly reports the total and cap. Arc anchors follow the existing GEL BEDPE exporter; intervals and ruler labels are zero-based, half-open. Arcs with an anchor outside the viewport are omitted, with a count. The gene body, TSS and strand use the stored annotation; transcript/exon structures are not retained by the result store.

The four local BigWigs are read in a worker with a 2 Mb region, 64 MiB compressed query and 250,000 intervals per track limits. Tracks use a common absolute scale and 800 mean-signal bins. The minus lanes display negative absolute values, including for positive-valued minus tracks; mixed-sign inputs are reported. Pan, zoom, contrast selection and track-height controls operate on the saved locus without reanalysis. Model-based effects and track-derived coverage stay distinct, and the displayed responses are those of the exact saved features.

After reload the source File objects may be unavailable. Reselect the four original files for the chosen contrast and confirm them. The automatic lookup uses saved path, size and modification time; manual relinking checks name and size. These checks do not prove identity. The saved declaration of genome assembly is not proof of the BigWig assembly; contig names and lengths are checked between all four tracks, and conflicting assembly declarations block display. No reference genome service is fetched by the viewer. Selected files and derived results remain local; storage and source-file permissions are subject to the browser's lifetime and eviction rules.

## Validation status and release gate

The synthetic browser test executes actual local analysis, opens the persisted result and four source tracks, navigates and relinks after reload, switches between two contrast tracks without reanalysis, and observes browser requests. Unit tests cover signed binning and the exporter anchor. Passing these tests does not establish display equivalence with desktop IGV or cross-browser compatibility.

Desktop IGV 2.17.4 loaded a synthetic coordinate-only reference and the synthetic BEDPE arcs, but its BigWig signal lanes appeared flat in the initial comparison while the GEL viewer displayed signal. The cause remains unresolved; do not treat the desktop comparison as passed. An owner-approved HEL interval also completed the local viewer workflow without observed external requests; private screenshot and data remain outside Git. Desktop IGV opened the same source tracks and region, but the signal display was not sufficiently clear to establish parity, and the separately loaded arc did not yet match the newly selected browser candidate. A matched HEL comparison and a complete interaction-track comparison remain release gates until completed. Do not merge this development preview as a validated release until these gates and the complete regression suite pass. Private tracks, candidate coordinates, and screenshots are kept outside the repository.
